# The apps' logos

`scripts/container-apps.js` gives a container whose template has no icon the logo of the app its image runs, on the Docker tab. Each file here is a file of Dashboard Icons (`homarr-labs/dashboard-icons`, <https://dashboardicons.com>) at commit `d4b500dc40a8e1043b1581cabb7208892cf35472`, copied unchanged under another name, Apache-2.0. A name ending in `.dark.svg` is the variant Dashboard Icons draws for a dark background, and the plain name is the one for a light background.
